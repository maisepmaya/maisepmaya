### 🌸 About me

Hi! I'm Maíse, a Product Designer with **4+ years** building web and mobile products and a solid front-end background. I work from understanding users to prototyping in Figma and shipping side by side with developers.

I care about interfaces that feel effortless, consistent design systems, and accessibility from the very first sketch.

<br/>

- 🎨 &nbsp;Created the **white-label Design System** used across every site at **DBX Tecnologia**: tokens, light and dark themes, 22 components and a living style guide
- ♿ &nbsp;Solid background in **accessibility**, practiced alongside PwD specialists
- 🎓 &nbsp;Postgraduate @ **PUC-Rio** (incl. Interface Design & Prototyping) · B.Sc. in Computer Science *(GPA 9.4/10)*
- 🤖 &nbsp;Using generative AI (Claude, Copilot, Cursor) to work faster
- 🌎 &nbsp;Based in Recife, Brazil

### ✨ Featured work

**[🌐 My portfolio](https://maisepmaya.github.io)** · Case studies with real screens, interactive demos and the story behind each decision. Built by me in React, in Portuguese and English, with an accessibility panel (text size, high contrast, pause animations, readable font, reading guide).

**[Design System · DBX Tecnologia](https://maisepmaya.github.io/#design-system)** · A white-label system that unified sites with different looks, components and names. Each client applies their own brand color and the whole system follows. Research through the Support team, Figma prototypes, tokens and Vue + Quasar components.

**[HordaMaster](https://github.com/maisepmaya/front-end-avancado-pucrio)** · Web app that helps tabletop RPG game masters manage enemies in combat. **Every interface illustration was drawn by me**, and I built it in React + TypeScript. Praised for its usability and intuitive navigation. [▶ Live demo](https://maisepmaya.github.io/front-end-avancado-pucrio/)

**[Kibo](https://maisepmaya.github.io/#kibo)** · Mobile Augmentative and Alternative Communication (AAC) app. Pictograms adapt to the user's skin tone and hair color, with adjustable font size, contrast and text-to-speech. I was the lead front-end developer in React Native. Final thesis, graded 10/10.
